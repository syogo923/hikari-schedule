# 光ポータル Ver2.3（Excelデータ取込対応版）

## 主な機能
- 職員別の月間一覧
- 案件カードの3行表示（番船／表示名／製品名）
- 手動案件入力（番船欄は `S.` から開始）
- 得意先・表示名・製品名の候補入力と自由入力
- Excelデータ取込（提供された4種類の正常なExcelで解析確認済み）
- 明細ごとの取込除外、担当者、納期、製品名、数量、仕様の修正
- 検索、納期一覧、完了切替
- 社員・得意先・表示名・製品マスタ
- マスタの名称変更、並び替え、表示／非表示、削除

## 公開方法
ZIPを解凍し、中の全ファイル・フォルダをGitHubリポジトリのルートへ上書きアップロードしてコミットします。Netlifyが自動で再公開します。

`netlify` フォルダ、`public` フォルダ、`netlify.toml`、`package.json` を同じ階層に置いてください。
